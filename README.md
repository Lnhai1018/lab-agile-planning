# lab-agile-planning

## 本科数字经济学生实训智能体

本仓库包含为本科数字经济专业学生设计的实训教学资源，重点是**小样本商业数据的描述性统计分析**。

  - 理论知识能力（统计学基础、商业数据理解、数字经济知识）

  - 理论学习方法（课堂讲授、自主学习、小组讨论）
  - 实践操作方法（跟随式练习、案例实战、项目式学习）

  - 总结提升阶段：反思与提升
- **实训案例示例**
- **评估标准**
- **常见问题与解决方案**

### 3. 示例数据文件

#### [sample_data_sales.csv](./sample_data_sales.csv)
电商销售数据（50条订单记录）
- 包含订单编号、日期、产品类别、销售额、客户地区等字段
- 适用于练习1的所有分析任务

#### [sample_data_survey.csv](./sample_data_survey.csv)
课程满意度调查数据（30份问卷）
- 包含学员年龄、性别、各维度评分、学习时长等字段
- 适用于练习2的分组分析和相关性分析

## 🚀 快速开始

### 方式1：使用Excel/WPS（推荐初学者）

1. 下载示例数据文件：
   - [sample_data_sales.csv](./sample_data_sales.csv)
   - [sample_data_survey.csv](./sample_data_survey.csv)

2. 用Excel或WPS打开CSV文件

3. 按照[实训练习指导手册](./实训练习指导手册.md)中的步骤操作

### 方式2：使用Python（推荐有编程基础的学生）

1. 安装Python环境（推荐Anaconda）
```bash
# 安装必要的库
pip install pandas numpy matplotlib seaborn scipy
```

2. 下载数据文件和代码示例

3. 在Jupyter Notebook中运行代码

4. 参考[实训练习指导手册](./实训练习指导手册.md)中的Python代码
